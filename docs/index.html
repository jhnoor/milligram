Milligram

A live map of a C# codebase that shows where the risk is, with an AI agent at your side to fix it.

  • Architecture Namespaces drawn as components. Arrows that break the dependency rule turn red.
  • Mutants Stryker.NET mutation score: do your tests notice when the code changes?
  • CRAP Complexity × missing coverage. The code that is risky to touch.

Get it on GitHub, then run milligram in any .NET repo.
